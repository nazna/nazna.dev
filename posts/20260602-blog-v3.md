このブログは先日までは全く更新できず放置していました。

Cloudflare Pages で動いていましたが、 Pages ではなく Workers + Static Assets の構成が推奨されてるようだということは知っていたのですがなかなか取り掛かることができていませんでいた。

仕事の取り組んでいた案件もひと段落付きよいタイミングだったのでやってしまおうということで、以前よりこういう構成にしてみたいと考えていた形で v3 として実装しなおしました。

![1370x1167:eager](/images/20260531-v2.avif '記念撮影 v2')

おおよそ以下のような設計を考えていました。

- 画像の配信は R2 を直接公開はしたくなかったので Worker を通す
- JSX をテンプレートエンジンとして使いたいのでビルド必須
- できるだけきれいなHTMLを出力したいので、Markdownからの変換を制御したい

実装するにあたって以下の記事を非常に参考にさせていただきました。

- [react-markdown をやめて remark から自力でレンダリングするようにした話](https://blog.stin.ink/articles/replace-react-markdown-with-remark)
- [JSX をテンプレートエンジンとして使い、Vite でビルドする](https://blog.sasakiy84.net/articles/jsx-as-a-template-with-vite/)

結構勢いで作り替えたので変なところがある気がしていますが、見つけたら直せばいいやぐらいに思っています。  
Vite の自作プラグインは以前からちょっと触ってはいたのですが、 Environment API だったりとなかなか難しいなと思いましたが勉強にはなりました。

今回実装にあたってはAIも多少利用しました。
プライベートでは Pi + Kimi K2.6 を使っているのですが、実装例をいくつか作らせて参考にする分には有用でした。
やはり新しめの知識が不足していますし、モデルの性能かそのままでは使えないようなコードを出してくるので人間が理解して修正する必要はありましたが、自分はこのやり方はけっこうよいかもと思っています。

せっかく整備したので今年こそ小さな内容でも備忘録的に書いていければと思います。
